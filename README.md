# 採訊 CaiXun

資訊擷取產品落地頁，以 **Python / Flask** 建置。

## 啟動

```bash
pip install -r requirements.txt
python3 app.py
```

瀏覽器開啟 http://127.0.0.1:5000

## 結構

| 路徑 | 說明 |
|------|------|
| `app.py` | Flask 路由與網址表單驗證 |
| `templates/index.html` | 落地頁樣板 |
| `static/css/style.css` | 視覺與動效 |
| `static/js/main.js` | 區塊進場動畫 |
